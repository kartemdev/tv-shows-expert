# TV Shows Expert

Учебное приложение для поиска сериалов через бесплатный API, фильтрации результатов по жанрам и просмотра карточек сериалов.

## О проекте

Данное приложение поможет найти подходящий сериал на вечер, ознакомиться с описанием, рейтингом.

В данном проекте поставлена цель изучить несколько подходов "Silmple Architecture". А именно организация структуры компонентов и разделения их на View и Presenter. 

Подробнее о правилах архитектуры можно посмотреть в [документе об архитектуре](docs/architecture.md).

Токены, типографика, состояния элементов и правила адаптации описаны в [минимальной дизайн-системе](docs/design.md).

## Запуск проекта

Требования: Node.js `26.13.0` (версия указана в `.nvmrc`) и pnpm `10.33.0`.

Установить зависимости и запустить сервер разработки:

```bash
pnpm install
pnpm dev
```

По умолчанию сервер использует адрес http://localhost:3000. Если порт занят, актуальный адрес будет указан в терминале.

### Доступные команды

| Команда | Назначение |
| --- | --- |
| `pnpm dev` | Запустить сервер разработки |
| `pnpm build` | Проверить типы и собрать приложение в `dist/` |
| `pnpm preview` | Локально посмотреть собранное приложение |
| `pnpm typecheck` | Проверить типы без сборки |
| `pnpm lint` | Проверить код и форматирование через Biome |
| `pnpm lint:fix` | Применить исправления Biome |
| `pnpm check:lines` | Проверить лимит 120 строк для файлов исходного кода в `src/` |
| `pnpm check` | Проверить Biome, лимит строк и типы |
| `pnpm verify` | Проверить Biome, лимит строк и собрать приложение с проверкой типов |

## Структура проекта

```text
src/
  app/               # Точка входа в приложение, провайдеры, роутинг
  pages/             # Страницы, компоновка компонентов и подключение Provider
  components/        # View/Presenter частей интерфейса, их стили и локальные 
  api/               # Методы запросов, DTO и проверка ответов
  model/             # Сущности, мапперы, Context, reducer и общие хуки
  shared/            # Общий HTTP-клиент, стили, UI и утилиты
```
