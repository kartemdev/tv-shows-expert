# Работа с TV Shows Expert

Учебное приложение на React и TypeScript: поиск сериалов через TVMaze, фильтрация по жанрам и карточки результатов.

## Источники правил

- [README.md](README.md) — назначение проекта, структура, стек и запуск.
- [docs/architecture.md](docs/architecture.md) — источник архитектурных правил. Читай его перед изменением React-кода; не заменяй правила привычными соглашениями других архитектур.
- `package.json`, `tsconfig.json`, `biome.json` — актуальные команды и настройки инструментов.

Архитектурный документ меняй только по запросу на изменение самой архитектуры. UI сценария размещай в `src/components/`, методы запросов и DTO — в `src/api/`, сущности, мапперы, Context и общие хуки — в `src/model/`. API может использовать `shared`, но не импортирует модель, компоненты и страницы. Дорабатывай нужный слой и ветку компонентов; переносы и новые зависимости должны быть нужны для этой задачи.

## Инструменты и проверки

Используй версии Node.js из `.nvmrc` и pnpm из `package.json`. Зависимости уже используют pnpm; сохраняй этот менеджер и его lockfile.

- `pnpm check` — Biome, лимит строк исходников и проверка типов.
- `pnpm verify` — Biome, лимит строк и сборка с проверкой типов; выполняй после изменений исходников или конфигурации сборки.
- `pnpm lint:fix` — исправления Biome; для точечных правок можно передать пути: `pnpm exec biome check --write <пути>`.

Автоформатирование Markdown отключено, чтобы команды исправления кода не переписывали документацию. Для изменений только Markdown достаточно проверить содержание и ссылки.

Тестовый раннер пока не настроен. Проверка строк не проверяет границы View/Presenter и дерево владения — оценивай их по архитектурному документу. В результате работы указывай выполненные проверки и оставшиеся ограничения.
