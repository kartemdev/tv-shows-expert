# Дизайн интерфейса

TV Shows Expert сочетает тёмный первый экран, светлую выдачу и золотистый акцент. Основной шрифт — Manrope, курсивный акцент в заголовке — Playfair Display.

## Поиск и выдача

- На первом экране поиск запускается кнопкой «Искать» или Enter. Пустой запрос не отправляется.
- После первой отправки первый экран сжимается, а форма с введённым текстом появляется над результатами. Страница однократно прокручивается к ней. Компактный режим сохраняется до перезагрузки, включая пустую выдачу и ошибку.
- У результатов кнопки поиска нет: ввод запускает поиск с задержкой 300 мс, Enter — сразу. Повтор того же запроса после удаления пробелов по краям не запускает поиск во время загрузки и после успеха; после ошибки повтор разрешён.
- При обновлении предыдущая выдача остаётся видимой. Подпись запроса и счётчик относятся к показанным результатам. Очистка поля не сбрасывает выдачу, жанр, страницу и статус поиска.
- Жанры расположены перед карточками: «Все жанры», затем уникальные жанры полной выдачи по алфавиту. Выбранный жанр не меняет набор доступных фильтров. Счётчики показывают общее число совпадений выбранного жанра.
- Пагинация под карточками показывает по 3 сериала после фильтрации. Новый поиск, выбор и сброс жанра возвращают страницу 1. Переключение страниц не обращается к API. При единственной странице, загрузке, ошибке или пустой выдаче навигация скрыта.

## Компоновка и адаптация

| Область | Правило |
| --- | --- |
| Контент | Максимум 1380 px, боковые поля 36 px; при ширине ≤720 px — 18 px |
| Сетка карточек | 3 колонки при >1050 px, 2 при 721–1050 px, 1 при ≤720 px; промежутки 16 px |
| Карточка | До 288 px, по центру колонки; постер и его заглушки имеют пропорции 2:3 |
| Первый экран | До поиска занимает не меньше высоты окна; после поиска становится компактным. На телефоне в компактном режиме скрыты надзаголовок и подпись |
| Форма | До 620 px; в первом экране поле и кнопка стоят в строку с переносом при нехватке места |
| Панель поиска | Закреплена сверху при прокрутке. На телефоне содержит только форму, на широком экране — также бренд и счётчик |
| Подвал | Тёмный, с брендом и ссылкой на TVMaze; на телефоне содержимое выстроено в колонку |

Длинные названия, жанры и кнопки пагинации переносятся без горизонтальной прокрутки. Заголовок выдачи — «Результаты поиска», под ним запрос и счётчик.

## Карточки и элементы управления

Карточка расположена на фоне выдачи без рамки. Рейтинг со звездой находится слева внизу постера. Под ним — подчёркнутое название со ссылкой на TVMaze, жанры через «·» и описание. Описание занимает четыре строки; длинный текст обрезается с многоточием, полный остаётся доступен скринридеру и на странице сериала.

При отсутствии данных показаны «Нет постера», «Нет оценки», «Жанры не указаны» и «Описание отсутствует.». Ошибка загрузки постера заменяет изображение заглушкой того же размера. Рейтинг `0` отображается числом.

Кнопки действий золотистые с тёмным текстом. Выбранный жанр выделен контрастной заливкой и галочкой, текущая страница — золотистой заливкой. Поле имеет видимую подпись и контрастную границу. Минимальная высота контролов — 48 px, область нажатия — не меньше 44 px.

## Состояния

| Состояние | Отображение |
| --- | --- |
| Первая загрузка | «Загрузка…» и три скелетона размером с постер |
| Обновление | Предыдущие результаты и индикатор загрузки у поля без изменения высоты панели |
| Нет результатов | «Ничего не найдено» с предложением изменить название |
| Нет совпадений жанра | Сообщение с выбранным жанром и кнопка «Сбросить жанр» |
| Нет жанров | Пояснение о недоступности фильтрации вместо группы жанров |
| Ошибка | Контрастное сообщение и кнопка «Повторить» для последнего отправленного запроса; предыдущая выдача сохраняется |

## Доступность и стили

Одновременно доступна одна форма поиска. При её переносе клавиатурный фокус переходит в новое поле; приход ответа фокус не перемещает. Результаты и смена страницы объявляются скринридеру, ошибки — как срочные сообщения. Выбранный жанр и текущая страница имеют доступные обозначения.

Фокус — контур 2 px с отступом 3 px. Контраст текста — не ниже 4.5:1, значимых границ и фокуса — 3:1. Ссылки подчёркнуты. При настройке уменьшенного движения анимации отключены, прокрутка мгновенная.

Актуальные значения палитры и фонов хранятся в [цветовых токенах](../src/shared/styles/colors.module.css), шрифтов, размеров и отступов — в [токенах оформления](../src/shared/styles/tokens.module.css). [Базовые стили](../src/shared/styles/base.module.css) задают типографику и состояния общих HTML-элементов.
